# Session — 28 June 2026

## Intro video upgrade (landscape + portrait)

### Problem
- `intro-portrait.mp4` was 540×960 (below 720p) — appeared soft on mobile retina screens
- `intro-landscape.mp4` was 1280×720 at 1.1 Mbps

### Source
Both high-resolution originals were already uploaded to WordPress media library:
- `initial_video_big_screen.mp4` — 1920×1080, ~20 Mbps
- `initial_video_small_screen.mp4` — 1080×1920, ~20 Mbps

### Fix
Downloaded from WordPress and re-encoded with ffmpeg (libx264, CRF 23, slow preset, no audio, faststart):

| File | Before | After |
|---|---|---|
| `public/intro-landscape.mp4` | 1280×720, 1.1 Mbps | 1920×1080, 3.7 Mbps |
| `public/intro-portrait.mp4` | 540×960, 0.7 Mbps | 1080×1920, 4.4 Mbps |

ffmpeg command pattern used:
```bash
ffmpeg -y -i "<wordpress-url>" -c:v libx264 -crf 23 -preset slow -an -movflags +faststart "public/<output>.mp4"
```
