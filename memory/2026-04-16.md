## #16 — ACF setup, Global Fields, `getGlobalSettings()` pattern

### ACF

- **Show in REST API** must be **ON** for every field group that the frontend reads; otherwise ACF can appear empty in JSON.
- ACF **Gallery** and **Repeater** are Pro-only; free tier pushes us toward **media tags** or other patterns for large galleries.

### Global Fields (Global Settings page)

| Field | Name | Type | Frontend |
|-------|------|------|----------|
| Logo Image | `logo_image` | Image | Intro (`app/page.tsx`) |
| Bio Image | `bio_image` | Image | Not wired to biografia pages yet |

### `getGlobalSettings()` pattern

- Fetch: `GET ${WP_API_URL}/pages?slug=global-settings&acf_format=standard`
- Use `cache: 'no-store'` while iterating (or `revalidate` when stable).
- Cast `page.acf` to `WPGlobalSettings` after verifying the page exists.

## Media tags setup (WordPress)

**Goal:** Free, scalable galleries without ACF Pro — tag media in the library and query by tag from Next.js.

1. **Plugin:** **Code Snippets** (or equivalent) to register custom taxonomy terms if not using a dedicated “Media Tags” plugin UI.
2. **PHP:** `add_media_tags()` (or snippet that registers **`media_tag`** taxonomy for attachments) so the REST API exposes `?media_tag={id}` on `/wp/v2/media`.
3. **Director de fotografía:** tag ID **5** corresponds to the **director-de-fotografia** portfolio strip (used in `getGalleryImages(5)`).

Upload images in WordPress → assign the correct **media tag** → they appear in the horizontal strip on the matching page.

## Code changes (2026-04-16) — gallery wiring

### `GalleryImage` interface — `types/wordpress.ts`

```typescript
export interface GalleryImage {
  id: number;
  url: string;
  alt: string;
  caption: string;
}
```

### `getGalleryImages(tagId)` — `lib/wordpress.ts`

- `GET` … `/wp/v2/media?media_tag=${tagId}&per_page=100`
- Maps each item to `{ id, url: source_url, alt, caption }`
- Uses the **Hostinger temp domain** (same host as `WP_API_URL`)

### Async server component — `app/director_de_fotografia/page.tsx`

- Default export is `async`; `await getGalleryImages(5)` at top of component.
- Renders a horizontal scroll strip of `<img>` elements (not `next/image` for this strip — plain `img` + CSS).

### `.strip-img` — `app/globals.css`

- Fixes strip height/width so images don’t collapse or scale wrong in the flex row: `height` via `clamp`, `width: auto`, `max-width: none`, `flex-shrink: 0`.
- Larger breakpoint at `min-width: 1200px` increases clamp range.

## #17 — Key lessons

1. **Validate REST API on day one** — `yourdomain.com/wp-json/` is wrong when DNS points to Vercel; use the Hostinger hostname for API calls.
2. **ACF “Show in REST API”** must be on for fields you read from JSON.
3. **Next.js `fetch` caching** — use `cache: 'no-store'` during development for global settings; consider `revalidate` for production.
4. **ACF Gallery/Repeater = Pro** — plan free alternatives (media tags, custom post types, or headless CMS) for hundreds of images per section.
5. **Patrick (Hostinger)** — optional long-term fix: **subdomain** (e.g. `cms.nahuelbeade.com`) pointing to Hostinger so API URLs are stable and human-readable instead of only the temp domain.
