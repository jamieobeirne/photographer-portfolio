## Video compression fix

- **Problem:** Intro page showed black screen locally
- **Root cause:** `logo_video` was 256MB — too large to buffer on load

  2. Uploaded compressed file to WordPress Media Library
  3. Updated ACF `logo_video` field to point to new file URL
  4. Hard refresh (`Ctrl+Shift+R`) to clear browser cache
- **Result:** Local and live Vercel site both load video correctly
- **Live video URL:** `https://lightcyan-deer-205982.hostingersite.com/wp-content/uploads/2026/06/logo_video_compressed.mp4`
