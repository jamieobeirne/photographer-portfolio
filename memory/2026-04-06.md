## Lessons Learned

1. **Get Hostinger access on day one — before any DNS changes are made.** The missing A record that caused hours of confusion was spotted and fixed in 2 minutes once hPanel access was available.
2. **Hostinger Request Access flow** — you can request access yourself from hPanel → Request Access → enter client's Hostinger email. No need for the client to initiate it.
3. **WordPress Admin is in hPanel** — the WordPress Admin button on the hPanel home screen gives direct access without needing a server URL.
4. **When DNS points to Vercel, WordPress can't be accessed via the main domain.** Always use hPanel to access WordPress admin.
5. **DNS propagation + Vercel re-verification** are two separate steps. Always hit Refresh in Vercel after a DNS change.
6. **Both the A record and CNAME are required** — CNAME alone for `www` is not enough. The root `@` A record must also be present.
