## Global CSS changes (`app/globals.css`)

```css
main {
  display: flex;
  flex-direction: column;
  min-height: 100vh;
}
footer {
  margin-top: auto !important; /* !important needed — Tailwind mt-* class specificity beats element selector */
}
```

Sticky footer: footer always pinned to bottom. `!important` required because Tailwind class specificity (0,1,0) beats CSS element selector (0,0,1).
