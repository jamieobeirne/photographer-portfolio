## CRITICAL — WordPress REST API Configuration

### The Problem
`nahuelbeade.com/wp-json/` returns **403 Forbidden** because:
- The domain points to **Vercel**, not Hostinger
- Requests to `/wp-json/` hit Vercel, which knows nothing about WordPress

### The Fix ✅
Use the **Hostinger temporary domain** to access WordPress directly:
```
https://lightcyan-deer-205982.hostingersite.com/wp-json/wp/v2
```

This is set in `lib/wordpress.ts`:
```typescript
const WP_API_URL = 'https://lightcyan-deer-205982.hostingersite.com/wp-json/wp/v2';
```

### Important ACF Setting
In **ACF → Field Groups → Global Fields** (and all future field groups):
- **Show in REST API** must be toggled **ON**
- Without this, ACF returns empty `[]` even if fields have data

### Important Next.js Setting
Use `cache: 'no-store'` in fetch calls to avoid stale cached responses:
```typescript
const res = await fetch(url, { cache: 'no-store' });
```
Can switch to `{ next: { revalidate: 3600 } }` for production once stable.

### lib/wordpress.ts — Added:
```typescript
import { WPGlobalSettings, WPPage } from '@/types/wordpress';

export async function getGlobalSettings(): Promise<WPGlobalSettings> {
  const url = `${WP_API_URL}/pages?slug=global-settings&acf_format=standard`;
  const res = await fetch(url, { cache: 'no-store' });

  if (!res.ok) throw new Error(`Failed to fetch global settings: ${res.status}`);

  const pages = await res.json();
  if (!pages.length) throw new Error('Global Settings page not found');

  const page = pages[0] as WPPage;
  return page.acf as unknown as WPGlobalSettings;
}
```

## Lessons Learned

1. **Test the REST API on day one** — visit `yourdomain.com/wp-json/` before building anything that depends on it.
2. **Hostinger shared hosting: domain points to Vercel, not Hostinger** — always use the Hostinger temporary domain (`lightcyan-deer-205982.hostingersite.com`) for WordPress REST API calls.
3. **ACF "Show in REST API" must be ON** — fields return empty `[]` without this even if data exists.
4. **Next.js caches fetch responses aggressively** — use `cache: 'no-store'` during development. Switch to `revalidate` for production.
5. **ACF Gallery & Repeater = Pro only** — plan for this early. Free ACF only supports basic Image fields.
6. **Divi plugin on headless WordPress** — harmless but unnecessary. It only affects WordPress admin, not the Next.js frontend.
7. **Patrick from Hostinger support** was helpful — human agents can make server-level changes that the AI cannot.
