### lib/wordpress.ts — Added:
```typescript
import { WPGlobalSettings, WPPage } from '@/types/wordpress';

export async function getGlobalSettings(): Promise<WPGlobalSettings> {
  const res = await fetch(
    `${WP_API_URL}/pages?slug=global-settings&acf_format=standard`,
    { next: { revalidate: 3600 } }
  );

  if (!res.ok) throw new Error(`Failed to fetch global settings: ${res.status}`);

  const pages = await res.json();
  if (!pages.length) throw new Error('Global Settings page not found');

  const page = pages[0] as WPPage;
  return page.acf as WPGlobalSettings;
}
```

## Lessons Learned

1. **Test the REST API early** — on day one, visit `yourdomain.com/wp-json/` and confirm it returns JSON before building anything that depends on it.
2. **Hostinger shared hosting blocks the REST API** via ModSecurity — this is a known issue and not fixable from hPanel on the Premium plan. Only a human support agent or server-level access can fix it.
3. **ACF Gallery and Repeater fields are Pro only** — free ACF only supports basic field types (Image, Text, etc.).
4. **ACF Options Page is Pro only** — workaround is to create a Draft WordPress page called "Global Settings" and attach fields to it. Next.js can query it by slug regardless of publish status... but only once the REST API is unblocked.
5. **All content was placeholder** — videos and images were never connected to WordPress. The REST API block went undetected until we tried to connect real content today.
6. **WordPress Admin access:** Hostinger hPanel → `nahuelbeade.com` → WordPress Admin button. No direct URL needed.
