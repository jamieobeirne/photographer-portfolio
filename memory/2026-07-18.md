### Techniques that work (and don't)
- Chrome downloads land on the user's **Desktop**, not Downloads.
- Heavy wp-admin pages (Global Settings editor w/ Divi) freeze CDP — script injection times out. Use a light page (profile.php) instead.
- **REST with cookie auth works from any wp-admin page**: `fetch('/wp-admin/admin-ajax.php?action=rest-nonce')` → use as `X-WP-Nonce`. Used to set ACF values (`POST /wp/v2/pages/53 {acf:{...}}` — ACF REST integration is on) and media alt/tags. This is the reliable path; avoid the editor UI.
