### Vertical spacing rhythm
All three gaps use the same standard Tailwind responsive scale:

| Gap | Mobile | sm+ |
|---|---|---|
| Header (PageHero) → video | `mt-12` (48px / 3rem) | `sm:mt-24` (96px / 6rem) |
| Video → bio photo | `mb-12` (48px / 3rem) | `sm:mb-24` (96px / 6rem) |
| Bio photo → footer | `mb-12` (48px / 3rem) | `sm:mb-24` (96px / 6rem) |

Tailwind spacing uses `rem` internally — correct choice for layout gaps
(vs `em` which is relative to the element's own font size, better for
component-internal padding like button padding).
